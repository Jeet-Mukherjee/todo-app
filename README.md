# Todo App

A modular todo application built with vanilla JavaScript to practice clean code architecture and state management.

## Features

- Add, edit, and delete tasks
- Mark tasks as completed
- Filter tasks (All/Pending/Completed)
- Clear completed tasks
- Data persistence using localStorage

## Status: Work in Progress

Currently working on:
- [ ] escape event for add task
- [ ] clear all task button
- [ ] tasks search/filter by text
- [ ] undo last delete
- [ ] task reordering (drag & drop or up/down buttons)


## Technologies Used

- Vanilla JavaScript (ES6 modules)
- HTML5
- CSS3

## What I Learned

- ES6 module system and separation of concerns
- State management patterns
- Event delegation
- Browser localStorage API
- DOM manipulation best practices

## How to Run

Simply open `index.html` in a web browser. No build process required!
