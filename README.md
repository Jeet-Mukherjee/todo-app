# Todo App

A modular todo application built with vanilla JavaScript to practice clean code architecture and state management.

## Features

- Add, edit, and delete tasks
- Mark tasks as completed
- Filter tasks (All/Pending/Completed)
- Clear completed tasks
- Clear all tasks
- Data persistence using localStorage
- Tasks search/filter by text(with counter)
- Undo last delete(single-task delete only, restore to original position in state)
- Pending tasks reordering (up/down buttons)
